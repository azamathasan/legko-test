Установка и запуск:
1. Убедитесь, что на вашем устройстве установлен Docker Compose. Если не установлен, то установите.
2. В командной строке перейдите в корневую папку проекта (например, если вы скачали проект в папку Home, то в терминале нужно выполнить команду cd /home/legko-test)
3. Выполните команду docker compose up -d --build
4. Откройте браузер и введите в адресную строку http://0.0.0.0:3000/
5. На веб-странице проекта в текстовое поле введите URL какого-либо изображения (например, https://www.gstatic.com/webp/gallery/1.jpg)
6. Нажмите кнопку "Скачать" и убедитесь, что появилось сообщение об успешном скачанном файле с указанием размера (в байтах) и среднем времени загрузки (в мс).
7. Для остановки проекта из корневой папки проекта в командной строке выполните docker compose down
